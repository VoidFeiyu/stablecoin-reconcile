# Chain Ledger

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · 日本語 · [한국어](README.ko.md) · [Español](README.es.md)

Chain Ledger は暗号資産で代金を受け取る個人や小規模チーム向けのオープンソース入金照合ツールです。普段のウォレットで受け取り、ブラウザーで送金を確認して請求書と照合し、記録を出力できます。

## 始め方

リポジトリを取得し、プロジェクトのディレクトリで Python 3 のローカルサーバーを起動します。

```sh
python -m http.server 8080 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8080/` を開きます。「取引確認」で「分割払いの例を試す」を選ぶと、2件のデモ入金を1件の請求書と照合できます。言語メニューで日本語を選べます。ブラウザーは選択を記憶し、支払リンクやダウンロードした支払ページには作成時の言語が使われます。

## 機能

- 請求書の作成、CSVの入出力、ダウンロード可能な支払ページ。CSVテンプレートは6言語で利用できます。
- 請求書番号、顧客、受取アドレスで検索し、一部入金や過入金で絞り込みます。顧客名はいつでも編集でき、入金を紐付ける前は金額と受取アドレスも変更できます。
- ハッシュや署名で複数の取引を確認するか、受取アドレスで最近の入金を検索します。
- 分割払いと過入金の追跡、入金の紐付け解除、例外メモ、最近の操作履歴。
- ネットワークと資産ごとの台帳、およびJSONでのバックアップと復元。
- Base、Ethereum、Arbitrum One、OP Mainnet、Polygon PoS、Avalanche C-Chain、BNB Smart Chain、Solanaに対応します。EVMネットワーク、RPC、ERC-20トークンは追加でき、Solanaでは互換性のあるメインネットRPCを追加できます。

取引確認には読み取り専用のRPCを使い、請求書と設定はブラウザーに保存します。端末やサイトのアドレスを変える前に、台帳ごとにバックアップを出力してください。カスタム資産を使う場合は、復元前に同じネットワークとコントラクトを設定します。
